## 7. SSH 접속과 known_hosts

`ssh 사용자@IP`
`~/.ssh/known_hosts` 서버의 host key 저장
저장된 키 vs 지금 서버가 보낸 키
-> 같으면 통과 / 다르면 경고 + 접속 거부
따라서 처음 접속 시 서버에서 보내주는 키를 저장시켜놓는다.
MITM, REMOTE HOST IDENTIFICATION HAS CHANGED 경고
`ssh-keygen -lF <IP>` / `ssh-keygen -lf <키.pub>` fingerprint 대조
`/etc/ssh/ssh_host_*` 권한과 소유자(root)
host key의 소유자가 root인 이유
host key는 서버의 신분증이다.
유저가 키를 가지고 있으면 그 유저가 해킹당했을 때, 가짜 서버를 만들 수 있음. 보호 장치가 무력해짐.
+ 키를 실제로 사용하는 sshd가 root로 실행됨!
