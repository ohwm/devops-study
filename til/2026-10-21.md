서비스가 죽었을 때, 가장 먼저 보는 두 가지
-> systemctl, journalctl

## 1. systemd와 systemctl

systemd = 서비스를 켜고 끄고 관리하는 관리자
`systemctl status <서비스>` 상태, PID, 최근 로그
`systemctl list-units --type=service --state=running` 실행 중인 서비스 목록

## 2. journalctl

journal = 서비스 로그를 모아두는 곳
`journalctl -u <서비스>` 특정 서비스(unit) 로그
`-f` 실시간 (tail -f와 같은 개념)
`--since "1 hour ago"`, `--since today`
`-p err` 에러만 / `-b` 이번 부팅 이후

## 3. ssh 로그 읽기

`Accepted publickey for ohwm from 192.168.64.1 port 54759 ssh2: ED25519 SHA256:...`
시간 / host / 프로세스[PID] / 메시지
192.168.64.1 = Mac, 192.168.64.2 = VM
port = 임시 포트(ephemeral port)
fingerprint = 클라이언트(내) 키

`Permission denied (publickey)`
괄호 안에 password가 없다는 건 서버가 publickey 방식만 받는 다는 뜻!
password로 로그인 하는 방식이 꺼져있다는 뜻.

`Connection closed ... [preauth]`
인증이 끝나기 전에 연결이 끊겼다는 뜻.

## 4. SSH 키 인증 (10-18 실습 정리)

`ssh-copy-id` 공개키를 서버에 등록
`known_hosts` vs `authorized_keys`
Mac vs VM
서버 키 저장 vs 사용자 키 저장

`~/.ssh/config` Host 별칭 -> `ssh devbox`

## 5. 비밀번호 로그인 끄기

`/etc/ssh/sshd_config.d/00-no-password.conf` -> PasswordAuthentication no
파일 이름 00- 인 이유
[sshd]는 처음 읽은 값을 쓴다.
같은 설정이 두 번 나와도 처음에 본 것만 적용
따라서 password 적용을 no로 해야하기 때문에 00-(최우선 순위)를 파일 이름으로 한다.

* 주의할 점: 다른 대부분의 프로그램은 나중에 읽은 값이 이긴다.
프로그램마다 다르니 확인하고, 최종 값은 sshd -T로 검증한다.

`sudo sshd -t` 문법 검사
`sudo sshd -T` 최종 적용 값 확인
lockout 방지: 기존 접속 창은 닫지 않고 새 창에서 테스트
