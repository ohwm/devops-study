- 인자 없음 → 지금 나에게 가장 부족하다고 생각하는 부분 문제내기
- 날짜 (2026-10-14) → 해당 날짜의 TIL 내용으로 문제내기
- 주제 (linux) → 공부했던 내용 중 Linux에 관한 내용으로 문제내기
- Phase (phase0) → 해당 Phase에 대한 내용으로 문제내기

til/ 폴더 내용과 notes/의 틀린 문제를 모아서 문제 내기

객관식 2문제, 주관식 1문제, 실습 3개
명령어 실습을 위주로 했으면 좋겠어. (10분 정도)
문제를 한번에 한 개씩 내주고, 문제의 정답을 내가 말했을 때 채점해줘. (한 문제씩 채점)
그리고 내가 "아예 모르겠어."라고 말하면 바로 정답을 말해줘.

틀렸을 때는 notes/에 wrong.md 파일에
틀린 문제, 그 틀린 문제의 핵심 개념을 담아줘.
wrong.md에 계속해서 추가하면 돼.

실습은 labs/ 같은 연습용 폴더에서만, 파일 삭제나 시스템 설정 변경 문제는 내지 않기
